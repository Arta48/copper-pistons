# Copper Pistons

A lightweight Fabric mod introducing copper pistons that function **strictly without Quasi-Connectivity (QC)**.

Say goodbye to accidental diagonal BUD-powering: copper pistons activate only when a redstone signal is directly applied to them.

---

## ✨ Features

* **Zero Quasi-Connectivity:** The ideal solution for ultra-compact vertical redstone wiring and high-density contraptions without unintended BUD activations.
* **Two Piston Variants:**
    * **Copper Piston** — pushes up to 12 blocks upon receiving direct signal.
    * **Honey Copper Piston** — coated in golden amber honey instead of slime; pushes and pulls blocks back.
* **Utility for Underused Resources:** Gives a practical purpose to copper ingots, basalt generators, and beekeeping.
* **Authentic Vanilla Look:** Perfectly mirrors vanilla extension animations, shortened rod geometry, and retraction.
